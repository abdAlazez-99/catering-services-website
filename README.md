# 🍽️ Catering Services Website

A professional catering services web application designed and developed using HTML5 and CSS3, featuring a structured custom CSS and responsive layout.

---

## 🚀 Features
- **Fully Responsive Design:** Seamlessly adapts to various screen sizes with a fully functional navigation bar and mobile burger menu.
- **Modular CSS Architecture:** Organized stylesheets (`global.css`, `framework.css`, `home.css`) for easy maintenance and scalability.
- **Icons & Typography:** Integrated with Font Awesome 7 and Google Fonts (`Open Sans` and `Playball`).

---

## 📂 Project Architecture

```text
├── css/
│   ├── all.min.css       # Font Awesome icons stylesheet
│   ├── framework.css     # Custom CSS layout & utility classes
│   ├── global.css        # Global variables, reset rules & header styles
│   └── home.css          # Home page specific styles
├── img/                  # Images and assets
├── pages/                # Additional pages (Booking, Blog, Team, etc.)
├── webfonts/             # Font Awesome webfonts
├── .gitignore            # Ignored files and folders (including DEMO/)
└── index.html            # Main landing page
