# 🍽️ Catering Services Website

A professional, fully responsive web application built for a modern catering and hospitality service provider. Developed using semantic **HTML5**, clean **CSS3**, and structured with a modular architectural approach to ensure scalability, maintainability, and high performance.

---

## 🌟 Key Features & Highlights

- **Responsive Mobile-First Navigation:** Fully adaptive layout featuring a flexible header, dropdown menus, and a responsive mobile burger menu for seamless browsing across all screen sizes.
- **Modular CSS Architecture:** Clean separation of concerns with dedicated stylesheets for global rules, layout frameworks, and page-specific styles.
- **Dynamic Content Sections:** Includes a rich landing section, services showcase, "About Us" breakdown, latest events, and company statistics/facts.
- **Modern Typography & Vector Icons:** Integrated with **Font Awesome 7** for crisp icons and Google Fonts (**Open Sans** & **Playball**) for an elegant aesthetic.

---

## 🛠️ Tech Stack & Concepts

- Markup & Structure: Semantic HTML5 (<header>, <nav>, <section>, <ul>, <a>)
- Styling & Layout:
  - CSS3 Flexbox & CSS Grid
  - Custom Properties (CSS Variables) for dynamic theming and easy maintenance
  - Responsive Media Queries
- Assets & Icons: Font Awesome 7, Google Fonts

## 📂 Project Architecture

```text
catering-services-website/
│
├── css/
│   ├── all.min.css       # Font Awesome 7 icon library stylesheet
│   ├── framework.css     # Custom CSS layout utility classes and helper rules
│   ├── global.css        # CSS variables, root tokens, reset rules, and header styles
│   └── home.css          # Page-specific styles for the landing/home page
├── img/                  # Graphic assets, banners, and promotional media
├── pages/                # Supplementary sub-pages (Booking, Blog, Team, Testimonials, 404)
├── webfonts/             # Font Awesome font files (woff2)
├── .gitignore            # Git exclusion rules (ignoring DEMO and local build folders)
└── index.html            # Main entry point and landing page
```
